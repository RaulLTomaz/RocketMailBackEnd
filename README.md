# RocketMail BackEnd

Backend API for RocketMail, a social platform inspired by Twitter/X, developed with FastAPI and PostgreSQL.

## 🚀 Technologies

* Python
* FastAPI
* PostgreSQL
* SQLAlchemy
* JWT Authentication
* REST API
* Git

## 📌 Features

* User authentication
* JWT token authorization
* Post creation and management
* Feed system
* Modular backend architecture
* Relational database structure
* RESTful API endpoints

## 🧠 Project Purpose

RocketMail was created as a personal full-stack software engineering project focused on backend development, API architecture, authentication systems, and database modeling.

The goal of the project is to improve practical experience with scalable backend applications and modern web/mobile integration.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/RaulLTomaz/RocketMailBackEnd
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
uvicorn main:app --reload
```

## 🗄️ Database

This project uses PostgreSQL as the primary relational database.

Configure your database connection variables before starting the application.
